## 課題2: 変数を使った自己紹介

### 目標
変数を使ってデータを保存し、表示してみましょう。

### 問題
自分の情報を変数に代入して、自己紹介文を作成してください。

**必要な変数:**
- `$name`: 名前
- `$age`: 年齢
- `$hobby`: 趣味

**出力例:**
```
私の名前は山田太郎です。
年齢は25歳です。
趣味は読書です。
```
