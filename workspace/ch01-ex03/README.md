## 課題3: データ型の理解

### 目標
異なるデータ型の変数を作成し、それぞれの型を確認してみましょう。

### 問題
以下のデータ型の変数を作成してください。

1. **String（文字列）**: 好きな食べ物
2. **Integer（整数）**: 今日の日付（日）
3. **Float（浮動小数点）**: 身長（例: 170.5）
4. **Boolean（真偽値）**: PHPは楽しい（true）

それぞれの変数を `var_dump()` で表示して、型を確認してください。
