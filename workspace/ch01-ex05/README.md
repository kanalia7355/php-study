## 課題5: 総合演習 - プロフィール作成

### 目標
学んだ内容を組み合わせて、自分のプロフィールを作成しましょう。

### 問題
以下の情報を含むプロフィールを作成してください。

**必要な情報:**
- 名前（文字列）
- 年齢（整数）
- 身長（浮動小数点）
- 趣味のリスト（配列）
- 学生かどうか（真偽値）

**出力フォーマット:**
```
=== プロフィール ===
名前: [名前]
年齢: [年齢]歳
身長: [身長]cm
趣味: [趣味1], [趣味2], [趣味3]
学生: [はい/いいえ]
===================
```

## 提出
`main.php`に実装し、`// QUEST: NOT STARTED`を削除してください。

```sh
php scripts/quest.php check ch01-ex05
git add workspace/ch01-ex05
git commit -m "Complete ch01-ex05"

```
